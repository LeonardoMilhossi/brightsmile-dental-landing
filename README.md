# BrightSmile Dental Studio

Conceptual landing page for a fictional dental clinic, built as a portfolio project.

## Tech Stack
- Semantic HTML5
- Tailwind CSS (via CDN) + custom CSS
- Vanilla JavaScript

## Project Structure
brightsmile-dental/
├── index.html
├── README.md
└── assets/
├── css/
│   └── styles.css          # active/inactive tabs and list markers
├── js/
│   ├── tailwind-config.js  # brand font and color configuration
│   └── main.js             # service tabs and appointment form logic
└── images/
└── hero.jpg            # hero background image


## How to Run
Open `index.html` in a web browser. No installation is required (an internet connection is needed to load Tailwind CSS and the Inter font).

## Notes
- The form is for demonstration purposes only and does not submit data.
